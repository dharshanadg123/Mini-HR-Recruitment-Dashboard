# Mini HR Recruitment Dashboard

## Project Description
Mini HR Recruitment Dashboard is a web-based application developed to simplify the recruitment process and manage candidate applications efficiently. The system provides separate functionalities for candidates and administrators.

## Features

### Candidate
- User Registration and Login
- Browse Available Jobs
- Apply for Jobs
- Upload Resume
- Track Application Status
- Logout

### Admin
- Admin Login
- Add and Manage Job Vacancies
- View Candidate Applications
- Manage Candidate Information
- Generate Recruitment Reports

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Development Tools
- Visual Studio Code
- Anaconda Prompt

## Project Objective
The main objective of this project is to provide a simple and efficient platform for managing job recruitment activities, reducing manual work, and improving the management of candidate applications.

## Project Structure
The project contains the user interface pages for home, registration, sign-in, and other recruitment-related functionalities.
